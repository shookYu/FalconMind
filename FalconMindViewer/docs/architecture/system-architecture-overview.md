# FalconMind 系统整体架构设计

> **版本**: 1.0  
> **日期**: 2026-02-28  
> **状态**: 方案设计阶段

---

## 一、系统概述

### 1.1 设计目标

构建一个**端到端的无人机AI任务编排与监控系统**，实现从可视化流程设计 → 代码生成 → 任务部署 → 实时监控的完整闭环。

### 1.2 核心能力

| 能力 | 描述 |
|------|------|
| **零代码编排** | 通过拖拽节点创建复杂AI任务流程 |
| **一键部署** | 可视化流程直接部署到无人机集群 |
| **实时监控** | 3D可视化展示任务执行状态和结果 |
| **集群管理** | 多机协同、任务分配、负载均衡 |
| **数据闭环** | 任务结果反馈优化后续编排 |

## 三、核心组件详解

### 3.1 FalconMindBuilder（可视化编排工具）

**定位**: 用户与系统交互的入口，提供零代码任务编排能力

**核心功能**:
- **节点库管理**: 管理SDK提供的各类节点模板（感知、飞行、传感器等）
- **流程编辑器**: 拖拽式节点编排，支持连接验证、参数配置
- **版本控制**: 流程的版本历史、回滚、对比
- **代码生成**: 将可视化流程转换为可编译的C++代码

**技术实现**:
- 前端: Vue3 Composition API + SVG画布
- 后端: FastAPI + JSON文件存储（可升级SQLite）
- 代码生成: Jinja2模板 + 静态代码分析

**API设计**:
```
GET    /api/v1/templates          # 获取节点模板列表
GET    /api/v1/templates/{id}     # 获取模板详情
GET    /api/v1/flows              # 获取流程列表
POST   /api/v1/flows              # 创建新流程
PUT    /api/v1/flows/{id}         # 保存流程
POST   /api/v1/flows/{id}/deploy  # 部署流程到集群
POST   /api/v1/flows/{id}/generate # 生成代码
```

---

### 3.2 FalconMindViewer（实时监控工具）

**定位**: 任务执行的实时监控和态势展示

**核心功能**:
- **3D态势显示**: Cesium-based 3D地图，显示UAV位置、轨迹
- **实时遥测**: 位置、姿态、电量、GPS状态等
- **任务可视化**: 搜索区域、航点、检测结果、覆盖热力图
- **告警通知**: 低电量、失联、异常状态提醒

**技术实现**:
- 前端: Vue3 + CesiumJS + WebSocket
- 后端: FastAPI + WebSocket广播
- 数据源: ClusterCenter遥测服务

**数据流**:
```
UAV Telemetry → NodeAgent → ClusterCenter → WebSocket → Viewer
```

---

### 3.3 ClusterCenter（集群管理中心）

**定位**: 系统的核心大脑，负责任务调度、资源管理、数据汇聚

**核心模块**:

#### 3.3.1 Flow Manager（流程管理）
- 接收Builder传来的流程定义（JSON）
- 流程版本管理
- 流程→任务转换
- 代码生成触发

#### 3.3.2 Mission Manager（任务管理）
- 任务生命周期管理（创建→调度→执行→完成）
- 任务优先级和队列
- 任务状态跟踪
- 异常处理和重试

#### 3.3.3 UAV Manager（UAV管理）
- UAV注册和心跳管理
- 能力模型管理（载荷、续航、传感器）
- 在线/离线状态跟踪
- 负载均衡决策

#### 3.3.4 Telemetry Service（遥测服务）
- 汇聚所有UAV的遥测数据
- 实时数据清洗和过滤
- 历史数据存储
- 告警规则引擎

#### 3.3.5 Multi-UAV Coordinator（多机协同）
- 任务区域分割（等分、Voronoi）
- 冲突检测和避免
- 协同策略执行
- 故障重分配

#### 3.3.6 WebSocket Manager（实时通信）
- Viewer/Web客户端连接管理
- 消息广播和订阅
- 断线重连处理
- 消息队列和削峰

**技术实现**:
- 框架: FastAPI + asyncio
- 数据库: SQLite（开发）→ PostgreSQL（生产）
- 缓存: Redis（会话、状态）
- 消息队列: MQTT / RabbitMQ（可选）

---

### 3.4 NodeAgent（边缘代理）

**定位**: 运行在每台UAV上的代理服务，连接SDK和ClusterCenter

**核心组件**:

#### 3.4.1 Uplink Client（上行客户端）
- 订阅SDK TelemetryPublisher
- 遥测数据序列化（JSON）
- TCP/MQTT协议传输
- 断线缓存和重连

#### 3.4.2 Downlink Client（下行客户端）
- 监听ClusterCenter命令
- 消息解析和路由
- 确认机制（ACK）
- 超时重传

#### 3.4.3 Command Handler（命令处理器）
- 解析飞控命令（ARM/DISARM/TAKEOFF/LAND/RTL）
- 调用FlightConnectionService
- 执行结果反馈

#### 3.4.4 Mission Handler（任务处理器）
- 解析任务JSON
- 转换为行为树
- 执行监控和上报

#### 3.4.5 Message Ack Manager（消息确认管理）
- 跟踪待确认消息
- 超时检测（默认5秒）
- 自动重传（最多3次）
- 状态机管理（Pending→Ack/Timeout）

**技术实现**:
- 语言: C++17
- SDK: FalconMindSDK
- 协议: TCP Socket / MQTT（可选）
- 架构: 事件驱动 + 状态机

---

### 3.5 FalconMindSDK（核心SDK）

**定位**: 提供无人机AI感知和任务编排的基础能力

**核心模块**:
- **Pipeline**: 数据流编排框架
- **NodeFactory**: 节点工厂，支持自定义节点
- **Perception**: AI推理（检测、跟踪）
- **Flight**: MAVLink飞控接口
- **Mission**: 任务规划（搜索路径、行为树）
- **Sensors**: 传感器接口（相机、IMU、GNSS）

**技术实现**:
- 语言: C++17
- 推理: RKNN Toolkit2（ARM64）/ ONNX Runtime（x86）
- 飞控: MAVLink v2
- 构建: CMake 3.16+

### 4.1 流程设计到部署的数据流

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│   用户       │────►│   Builder   │────►│  ClusterCenter │────►│  NodeAgent  │
│  (设计流程)  │     │  (保存流程)  │     │  (编译部署)    │     │  (执行流程)  │
└─────────────┘     └─────────────┘     └─────────────┘     └─────────────┘
       │                   │                   │                   │
       │                   │                   │                   │
       ▼                   ▼                   ▼                   ▼
  ┌─────────────────────────────────────────────────────────────────────────┐
  │  1. 用户在Builder拖拽节点，创建流程                                        │
  │  2. Builder保存流程JSON到ClusterCenter                                     │
  │  3. ClusterCenter生成C++代码（Workflow Compiler）                          │
  │  4. ClusterCenter编译生成二进制（交叉编译到ARM64）                          │
  │  5. ClusterCenter通过MQTT下发部署命令到指定UAV的NodeAgent                  │
  │  6. NodeAgent接收命令，启动/更新Pipeline                                   │
  └─────────────────────────────────────────────────────────────────────────┘

│  (产生遥测)  │     │  (上报遥测)  │     │  (汇聚分发)   │     │  (展示遥测)  │
└─────────────┘     └─────────────┘     └─────────────┘     └─────────────┘
       │                   │                   │                   │
       │                   │                   │                   │
       ▼                   ▼                   ▼                   ▼
  ┌─────────────────────────────────────────────────────────────────────────┐
  │  1. SDK TelemetryPublisher 发布遥测数据                                   │
  │  2. NodeAgent UplinkClient 订阅并序列化为JSON                             │
  │  3. 通过TCP/MQTT发送到ClusterCenter                                       │
  │  4. ClusterCenter TelemetryService 接收并存储                             │

```

### 4.3 命令下发数据流

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│   Viewer    │────►│ ClusterCenter│────►│  NodeAgent  │────►│     UAV     │
│  (下发命令)  │     │  (转发命令)  │     │  (执行命令)  │     │  (响应命令)  │
└─────────────┘     └─────────────┘     └─────────────┘     └─────────────┘
       │                   │                   │                   │
       │                   │                   │                   │
       ▼                   ▼                   ▼                   ▼
  ┌─────────────────────────────────────────────────────────────────────────┐
  │  1. 用户在Viewer点击"紧急返航"                                            │
  │  2. Viewer发送POST /missions/{id}/cancel 到ClusterCenter                  │
  │  3. ClusterCenter生成命令JSON，通过MQTT下发到目标UAV的NodeAgent          │
  │  4. NodeAgent DownlinkClient 接收命令                                     │
  │  5. CommandHandler 解析命令类型（RTL）                                    │
  │  6. FlightConnectionService 发送MAVLink RTL命令到飞控                     │
  │  7. NodeAgent上报命令执行结果（ACK）                                      │
  └─────────────────────────────────────────────────────────────────────────┘
```

## 七、关键设计决策

### 7.1 架构选型

| 决策点 | 选择 | 理由 |
|--------|------|------|
| **Builder前端框架** | Vue3 CDN | 无需构建工具，快速部署，适合内网环境 |
| **Viewer 3D引擎** | CesiumJS | 开源、高性能、支持离线地图 |
| **ClusterCenter框架** | FastAPI | 高性能、异步支持、自动生成文档 |
| **NodeAgent语言** | C++17 | 与SDK同语言，性能要求 |
| **通信协议** | MQTT + WebSocket | MQTT适合设备通信，WebSocket适合实时展示 |
| **数据存储** | SQLite → PostgreSQL | 开发简单，生产可扩展 |

### 7.2 扩展性设计

1. **水平扩展**: ClusterCenter支持多实例部署，通过Redis共享会话
2. **插件机制**: Builder支持自定义节点模板，通过JSON Schema定义
3. **多协议支持**: NodeAgent支持TCP和MQTT，未来可扩展gRPC
4. **跨平台**: SDK支持x86和ARM64，NodeAgent同样支持

### 7.3 容错设计

1. **断线重连**: NodeAgent自动检测连接断开，指数退避重连
2. **消息确认**: 下行命令支持ACK机制，超时重传
3. **数据缓存**: 断线期间遥测数据本地缓存，恢复后批量上报
4. **降级模式**: ClusterCenter故障时，NodeAgent可执行预置安全任务
