## 项目概述

FalconMind 是一套完整的无人机智能任务系统，包含地面控制平台（FalconMindViewer）、边缘侧开发工具（FalconMindBuilder）、边缘自治代理（NodeAgent）和软件开发工具包（FalconMindSDK）四大核心组件。**所有飞控连接均为真实实现，通过 MAVLink 协议直接连接 PX4/ArduPilot，无模拟、无 Mock。**

### 🎯 核心能力

| 能力域 | 说明 |
|--------|------|
| **🎮 统一控制台** | FalconMindViewer 提供集群管理、实时监控一站式界面 |
| **🔧 边缘开发** | FalconMindBuilder 提供零代码可视化编排，直连 UAV 即时部署 |
| **🔌 离线自治** | NodeAgent 实现 P0/P1/P2 三层离线自治，断网仍可自主决策 |
| **🔗 真实飞控** | MAVLink 直连 PX4/ArduPilot，支持 SITL 仿真和真实硬件 |
| **🧠 AI 感知** | 基于 Rockchip NPU 的 YOLO 目标检测与跟踪 |
| **📊 任务编排** | Pipeline + NodeFactory 架构，可视化流程设计 |

### 🆕 最新进展

**✅ FalconMindBuilder 边缘侧开发工具完成** - 可视化编排、即时部署、离线 Cesium 地图

**✅ NodeAgent 离线自治系统 (P0/P1/P2 全部完成)** - 15,000+ 行代码，250+ 测试用例

#### 核心关系说明

### 三种开发模式详解

#### 模式对比表

| 开发模式 | 使用工具 | 开发方式 | 运行位置 | 技术门槛 | 部署方式 | 适用场景 |
|----------|----------|----------|----------|----------|----------|----------|
| **Builder 开发** | FalconMindBuilder | 可视化编排 | UAV 边缘 | ⭐ 低 | 配置解释执行，秒级生效 | 现场调试、快速原型、简单任务 |
| **Viewer 开发** | FalconMindViewer | 表单+地图配置 | 地面站 | ⭐⭐ 中 | 任务下发到 UAV | 集群任务、集中管理、协同规划 |
| **SDK 原生开发** | FalconMindSDK | C++ 手搓代码 | 编译部署 | ⭐⭐⭐⭐ 高 | 编译生成可执行文件 | 复杂算法、性能优化、深度定制 |

#### 模式一：Builder 边缘开发（零代码/低代码）

**定位**：现场快速开发、无需地面站、单人单机任务

**工作流程**：
```
┌──────────────────────────────────────────────────────────────────┐
│                    Builder 开发流程                              │
├──────────────────────────────────────────────────────────────────┤
│                                                                   │
│  1. 现场部署 UAV                                                 │
│     └─> 连接 UAV WiFi / 网线                                      │
│     └─> 浏览器访问 http://uav-ip:8080                             │
│                                                                   │
│  2. 可视化编排任务                                               │
│     └─> 拖拽节点：开始 → 搜索区域 → 返航                          │
│     └─> 地图标绘：在昌平公园区域绘制搜索范围                        │
│     └─> 配置参数：高度 100m，速度 8m/s，模式 网格搜索               │
│                                                                   │
│  3. 即时部署（解释执行）                                          │
│     └─> 点击"部署"按钮                                             │
│     └─> Builder 生成 Flow JSON                                    │
│     └─> FlowExecutor 解释执行（无需编译）                           │
│     └─> UAV 立即开始执行任务                                       │
│                                                                   │
│  4. 实时监控（可选）                                              │
│     └─> 3D 地图显示 UAV 轨迹                                       │
│     └─> 查看遥测数据（高度、速度、电量）                            │
│                                                                   │
│  【无需地面站 · 无需编译 · 秒级生效】                              │
└──────────────────────────────────────────────────────────────────┘
```

**技术特点**：
- ✅ **零代码**：拖拽式编排，无需编程基础
- ✅ **即时生效**：Flow JSON 解释执行，无需重新编译
- ✅ **离线可用**：部署在 UAV 上，无需地面站参与
- ✅ **现场调试**：现场发现问题，现场修改，现场验证
- ⚠️ **功能边界**：受限于预置节点类型，复杂逻辑需自定义节点

**典型应用场景**：
- 🔧 **现场调试**：外场测试时快速调整参数
- 🚀 **快速原型**：验证任务流程可行性
- 📋 **标准任务**：巡逻、搜索、拍照等常规任务
- 👤 **非程序员**：产品、测试人员也能编排任务

#### 模式二：Viewer 地面开发（集中管控）

**定位**：多机集群管理、任务分发、集中监控

**工作流程**：
```
┌──────────────────────────────────────────────────────────────────┐
|VR|│                    Viewer 开发流程                               │
├──────────────────────────────────────────────────────────────────┤
│                                                                   │
│  1. 地面站任务设计                                               │
|RP|│     └─> 操作员在 PC 上打开 Viewer                                 │
│     └─> 地图划定多机协同搜索区域（Voronoi 分割）                    │
│     └─> 为每架 UAV 分配子区域                                      │
│                                                                   │
│  2. 任务生成与下发                                               │
|HQ|│     └─> Viewer 生成任务 JSON / Protobuf                          │
│     └─> 通过 MQTT 下发给各 UAV 的 NodeAgent                        │
│     └─> NodeAgent 存储到 SQLite（持久化）                          │
│                                                                   │
│  3. UAV 执行任务（离线自治）                                      │
│     └─> NodeAgent 解析任务，调用 SDK 生成航点                       │
│     └─> SDK 上传航点到飞控                                         │
│     └─> UAV 自动飞行，NodeAgent 实时决策                           │
│                                                                   │
│  4. 实时监控与干预                                               │
|PM|│     └─> 遥测数据通过 WebSocket 实时推送到 Viewer                  │
│     └─> 发现目标自动上报                                          │
│     └─> 操作员可随时暂停/恢复/终止任务                             │
│                                                                   │
│  【集群管理 · 集中监控 · 协同规划】                                │
└──────────────────────────────────────────────────────────────────┘
```

**技术特点**：
- ✅ **集群视角**：多机任务协调、冲突检测、负载均衡
- ✅ **集中存储**：任务数据、遥测日志统一存储分析
- ✅ **实时监控**：Cesium 3D 地图实时显示机群位置
- ✅ **任务下发**：批量任务分发，支持断点续传
|HX|- ⚠️ **网络依赖**：Viewer 需要与 UAV 保持通信

**典型应用场景**：
- 👥 **多机协同**：机群搜索、编队飞行、协同搬运
- 📊 **数据管理**：遥测数据长期存储与分析
- 🏢 **指挥中心**：地面站集中管控整个机群
- 🔄 **任务调度**：动态任务分配、实时冲突解决

### 场景2：单机搜索任务（有网络）

```
|SW|1. 操作员在 Viewer 设计任务
   └-> 在地图上划定搜索区域
   └-> 选择搜索模式（网格/螺旋）

   └-> 转换为 JSON/Protobuf 格式

   └-> NodeAgent 使用 SDK 进行目标检测（RKNN）
   |WR|   └-> 发现目标 -> 通过 MQTT 上报 Viewer
   |RP|   └-> 实时遥测通过 WebSocket 推送到 Viewer

   └-> NodeAgent 自动返航（RTL）
   └-> 上传完整日志到 Console

  ├─ 检测到 MQTT 断开 > 5s

  ├─ 继续执行当前任务（本地 SQLite 存储）

  └─ UAV-001 作为 Leader 继续协调机群

  └─ 任务分配在机群内部完成

网络恢复后：
  └─ NodeAgent 批量同步离线期间的数据
  └─ 上报任务执行结果和发现的目标
```

cd FalconMindSDK/build

make -j4

# 运行 PoC 场景

## ❓ 常见误区澄清

**Q: Viewer、Builder、NodeAgent 有什么区别？**
- **Viewer** 是**地面指挥中心**，负责任务管理和集群监控，需要网络
- **Builder** 是**边缘开发工具**，部署在 UAV 上，提供可视化编排，**不依赖地面站**
- **NodeAgent** 是**边缘自治代理**，部署在 UAV 上，负责**离线决策**和任务执行

**Q: Builder 和 Viewer 的关系？**
- Builder 是**独立运行的边缘工具**，可以单独使用
- Viewer 可以**可选集成** Builder 的功能
- 类比：Builder = 本地 IDE（如 VS Code），Viewer = 云端协作平台（如 GitHub）

**Q: Builder 能离线使用吗？**
- ✅ **可以**。Builder 部署在 UAV 边缘设备上，浏览器访问即可使用
- ✅ **离线地图**：使用昌平公园默认位置，无需网络
- ⚠️ 如需下载卫星图瓦片，需要临时联网

**Q: 三者的版本如何管理？**
- SDK 作为库，版本号独立（v1.0.0）
- Builder 和 NodeAgent 依赖特定版本的 SDK
- Viewer 通过 API 版本与 Builder/NodeAgent 兼容
