Production TLS certificates setup

- Use Let's Encrypt with Certbot for production deployments.
- Steps:
  1. Ensure DNS records point to your server.
  2. Install Certbot and required packages for your OS.
  3. Run: certbot certonly --standalone -d your-domain.com
  4. Configure nginx to use the obtained certificates:
     ssl_certificate /etc/letsencrypt/live/your-domain.com/fullchain.pem;
     ssl_certificate_key /etc/letsencrypt/live/your-domain.com/privkey.pem;
  5. Enable HTTP -> HTTPS redirection and strict TLS configurations.

- Renewal: certbot renew --dry-run and automation via cron/systemd timers.

Note: In development, use the self-signed certs generated by the included script.
