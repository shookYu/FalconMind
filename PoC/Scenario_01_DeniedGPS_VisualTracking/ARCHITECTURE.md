# 拒止环境视觉跟踪 - 三种方式架构对比

## 总体架构原则

```
┌─────────────────────────────────────────────────────────────────────┐
│                    FalconMind 配置驱动架构                          │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│   Builder/Viewer 只生成配置 ───────────┐                           │
│                                        │                           │
│                                ┌───────▼───────┐                   │
│                                │  配置文件      │                   │
│                                │  • Flow JSON   │                   │
│                                │  • Mission YAML│                   │
│                                └───────┬───────┘                   │
│                                        │                           │
│                      ┌─────────────────┼─────────────────┐         │
│                      │                 │                 │         │
│                ┌─────▼─────┐    ┌────▼────┐    ┌──────▼──────┐   │
│                │FlowExecutor│    │Mission  │    │  SDK Native │   │
│                │(SDK)       │    │Executor │    │  Executable │   │
│                └─────┬─────┘    └────┬────┘    └──────┬──────┘   │
│                      │               │                │           │
│                      └───────────────┼────────────────┘           │
│                                      │                             │
│                                ┌─────▼─────┐                       │
│                                │   飞控    │                       │
│                                │ PX4/ArduPilot                      │
│                                └───────────┘                       │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

**核心原则:**
1. Builder/Viewer只生成配置（JSON/YAML）
2. 所有实时控制都在UAV边缘闭环（20Hz）
3. Viewer/Builder不参与实时控制，只监控

### 数据流

```
Phase 1: 任务创建
─────────────────
操作员 ──▶ Viewer地图绘制搜索区域
       │
       ▼
    生成Mission YAML
       │
       ▼
    POST /api/v1/missions
    {
      "mission_config": "...YAML内容..."
    }

Phase 2: 任务部署
─────────────────
Viewer ──▶ POST /api/v1/missions/{id}/deploy
       │
       │ MQTT下发到UAV
       ▼
    NodeAgent接收
       │
       ▼
    存储到SQLite
       │
       ▼
    调用SDK MissionExecutor

Phase 3: 执行（完全本地）
────────────────────────
MissionExecutor ──▶ 解析Mission YAML
       │
       ▼
    生成执行计划
       │
       ├────▶ VINS初始化
       │
       ├────▶ 起飞
       │
       ├────▶ 搜索（航点跟踪）
       │      └────▶ YOLO并行检测
       │
       ├────▶ 发现目标 → 悬停
       │
       ├────▶ 等待Viewer指令（目标选择）
       │
       └────▶ 启动IBVS跟踪（20Hz闭环）
              ┌──────────────────────┐
              │ while tracking:      │
              │   target = detect()  │
              │   cmd = ibvs(target) │
              │   mavlink.send(cmd)  │
              │   sleep(0.05) #20Hz  │
              └──────────────────────┘

Phase 4: 监控（Viewer被动接收）
──────────────────────────────
UAV ──▶ 遥测数据 (5Hz)
    │
    │ WebSocket
    ▼
Viewer ──▶ 显示位置/状态/跟踪质量
       │
       ▼
    操作员观察（不干预控制）
```

### 关键设计决策

1. **Viewer不直接参与控制**
   - Viewer只发送高层指令："开始跟踪目标#5"
   - 具体控制（vx/vy/vz/yaw_rate）在UAV本地计算
   - 避免网络延迟影响控制稳定性

2. **Mission配置驱动**
   - 所有参数在Mission YAML中配置
   - UAV本地解析执行，不依赖Viewer在线
   - 支持离线执行（NodeAgent预置Mission）

3. **弱网优化**
   - 遥测5Hz（足够监控）
   - 控制20Hz（完全本地）
   - 断网后任务继续，重连后同步结果

### 数据流

```
Phase 1: Flow编排
─────────────────
操作员 ──▶ 浏览器访问 http://uav-ip:8080
       │
       ▼
    从模板选择"拒止环境任务"
    或手动拖拽节点:
      Start → VINS Check → Takeoff → GPS Defense
              ↓
         Error Handler
       │
       ▼
    配置节点参数:
      - VINSCheck.min_confidence = 0.8
      - VisualServo.desired_distance = 30
       │
       ▼
    点击"部署"
       │
       ▼
    Builder生成完整Flow JSON

Phase 2: 解释执行
─────────────────
FlowExecutor ──▶ 加载Flow JSON
       │
       ▼
    构建执行图（节点+边）
       │
       ▼
    按拓扑序执行节点:
       │
       ├────▶ Start (触发)
       │
       ├────▶ VINS Check (条件)
       │       └─▶ 检查状态
       │       └─▶ 返回 true/false
       │
       ├────▶ Takeoff (动作)
       │       └─▶ 发送MAVLink指令
       │       └─▶ 等待完成
       │
       ├────▶ GPS Defense (后台)
       │       └─▶ 启动1Hz检测线程
       │       └─▶ 持续运行
       │
       ├────▶ Visual Servo (后台)
       │       └─▶ 启动20Hz控制循环
       │       └─▶ 持续运行
       │
       └────▶ Check End (条件)
               └─▶ 循环检查
               └─▶ 满足条件→结束

Phase 3: 弱网支持
─────────────────
特性:
  • Flow完全本地执行，不依赖通信
  • 可选的Viewer连接（仅监控）
  • 通信中断不影响任务
  • 本地存储遥测日志
```

### 与Viewer方式的对比

| 特性 | Builder | Viewer |
|------|---------|--------|
| **配置格式** | Flow JSON | Mission YAML |
| **编排方式** | 拖拽节点 | 表单填写 |
| **运行位置** | UAV边缘 | 地面站+UAV |
| **网络依赖** | 可选（可完全离线） | 需要（任务下发） |
| **适用场景** | 现场调试/快速原型 | 集群管理/集中监控 |
| **灵活性** | 中（预置节点） | 中（预定义参数） |

### 数据流

```
启动流程:
──────────
./launcher.sh config/mission.yaml
    │
    ▼
mission_launcher启动
    │
    ├──▶ 加载YAML配置
    │       └─▶ desired_distance: 30
    │       └─▶ desired_height: 10
    │       └─▶ pid_params: {...}
    │
    ├──▶ 启动navigation进程
    │       └─▶ VINS初始化
    │       └─▶ GPS防护启动
    │
    ├──▶ 启动perception进程
    │       └─▶ 加载YOLO模型
    │       └─▶ 初始化DeepSORT
    │
    └──▶ 启动gcs_bridge
            └─▶ 监听TCP端口

搜索阶段:
──────────
MissionController ──▶ 状态: SEARCHING
    │
    ▼
navigation ──▶ 生成搜索航点
    │
    ▼
MAVLink ──▶ 上传航点
    │
    ▼
飞控 ──▶ 执行航线

    perception (并行)
        │
        ├─▶ Camera 60Hz
        ├─▶ YOLO 20Hz
        ├─▶ DeepSORT
        └─▶ 检测到目标?
            │
            是
            ▼
        SharedMemory ──▶ 检测结果
            │
            ▼
        MissionController ──▶ 状态: TARGET_ACQUIRED
            │
            ▼
        悬停等待人工选择

跟踪阶段:
──────────
操作员 ──▶ 选择目标ID=5
    │
    ▼
/tmp/falconmind_cmd ──▶ MissionController
    │
    ▼
状态: TRACKING
    │
    ▼
启动control进程 (20Hz闭环)
    │
    ┌─────────────────────────────────────┐
    │ while True:                         │
    │   # 50ms周期                        │
    │   target = shm.get_detection(id=5) │
    │   if target:                        │
    │       cmd = ibvs.compute(target)   │
    │       mavlink.send_velocity(cmd)   │
    │   else:                             │
    │       lost_count += 1              │
    │       if lost_count > 10:          │
    │           break # 丢失              │
    │   usleep(50000) # 50ms             │
    └─────────────────────────────────────┘

监控:
──────
gcs_bridge (5Hz)
    │
    ├─▶ 读取所有进程状态
    ├─▶ 打包遥测数据
    └─▶ TCP发送
        │
        ▼
    Viewer (可选)
```

### 配置文件示例

```yaml
# mission.yaml (简洁版)
mission:
  id: denied_env_001
  type: denied_environment_tracking

search:
  area: [[40.0768, 116.3477], [40.0778, 116.3477], ...]
  altitude: 50.0
  pattern: LAWN_MOWER

tracking:
  target_class: person
  desired_distance: 30.0
  desired_height: 10.0
  max_speed: 8.0
  control_frequency: 20
  pid_params:
    kp_distance: 0.5
    ki_distance: 0.1
    kd_distance: 0.2

vins:
  init_timeout: 30.0

gps_defense:
  enabled: true
  check_interval: 1.0
```

```
┌─────────────────────────────────────────────────────────────────────┐
│                      三种方式核心差异                                │

### 选择决策树

```
需要集群管理/多UAV?
    │
    是 ──▶ Viewer方式
    │
    否
    │
需要现场快速调试?
    │
    是 ──▶ Builder方式
    │
    否
    │
需要深度定制/最高性能?
    │
    是 ──▶ SDK方式
    │
    否
    │
标准任务 ──▶ Builder方式（简单）或 Viewer方式（可监控）
