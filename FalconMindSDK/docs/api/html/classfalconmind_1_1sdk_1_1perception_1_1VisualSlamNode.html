Detailed Description

视觉SLAM节点 - 基于VINS-Fusion实现

功能：

  • 单目/双目相机输入
  • IMU数据融合
  • 实时位姿估计
  • 回环检测（可选）

输入Pad：

  • image_in: CameraFramePacket (图像数据)
  • imu_in: ImuSample (IMU数据，可选)

输出Pad：

  • pose_out: Pose3D (位姿)
