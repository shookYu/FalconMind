Detailed Description

FalconMindSDK - LiDAR Source Node Implementation

支持LiDAR设备：

  • Velodyne VLP-16, VLP-32, HDL-64E, VLS-128
  • Livox Mid-40, Mid-70, Horizon, Avia

功能：

  • UDP数据包接收与解析
  • 点云数据组装与去畸变（运动补偿）
  • 时间同步
  • 多设备支持
