2.3 NodeAgent 解耦架构
================================================================================

    编译时独立 (Build Time)
    =======================

    NodeAgent源码                 FalconMindSDK源码
    +-------------+               +-------------+
    |             |               |             |
    |  C++17代码  |               |  C++17代码  |
    |             |               |             |
    +------+------+               +------+------+
           |                             |
           | 独立编译                    | 编译为共享库
           v                             v
    +-------------+               +-------------+
    |             |               |             |
    |  nodeagent  |               | libfalconmind|
    |  (可执行文件)|               | _sdk.so     |
    |             |               | (共享库)    |
    +-------------+               +-------------+


    运行时解耦 (Runtime)
    ====================

    +-------------+                dlopen               +-------------+
    |             | -----------------------------------> |             |
    |  NodeAgent  |                                     |    SDK      |
    |             | <----------------------------------- |   共享库    |
    +------+------+            C API接口调用             +------+------+
           |                                                   |
           |  不链接SDK库                                       | 导出C接口
           |  (ldd无依赖)                                       |
           v                                                   v
    +-------------+                                     +-------------+
    |             |                                     |             |
    | 独立运行    |                                     | 工厂模式    |
    | 动态加载    |                                     | SdkInterface|
    |             |                                     |             |
    +-------------+                                     +-------------+


    接口契约 (Interface Contract)
    =============================

    +----------------------------------+
    |    SdkInterface.h                |
    |    (C API头文件)                 |
    +----------------------------------+
    |  - createServiceFactory()        |
    |  - createFlightConnection()      |
    |  - createPerceptionService()     |
    |  - createMissionService()        |
    |  - getVersion()                  |
    |  - ...                           |
    +----------------------------------+
                   |
        +----------+----------+
        |                     |
        v                     v
   NodeAgent包含          SDK实现
   仅此头文件             导出函数


    解耦优势
    ========

    +----------------+  +----------------+  +----------------+  +----------------+
    | 编译时独立     |  | 运行时解耦     |  | 版本兼容       |  | 语言无关       |
    |                |  |                |  |                |  |                |
    | 分别编译       |  | 动态加载       |  | 接口版本检查   |  | 可用其他语言   |
    | 不互相依赖     |  | 通过dlopen     |  | 保证兼容性     |  | 实现NodeAgent |
    +----------------+  +----------------+  +----------------+  +----------------+

================================================================================
                        四、关键设计决策
================================================================================

    +----------------+-----------------+-----------------------------------+
    | 决策项         | 选择            | 原因                              |
    +----------------+-----------------+-----------------------------------+
    | Builder位置    | 边缘侧(UAV上)   | 直连UAV、即时部署、可离线使用     |
    +----------------+-----------------+-----------------------------------+
    | Console与      | 并列可选        | 根据场景选择,Console可集成Builder |
    | Builder关系    |                 | 功能,两者独立运行                 |
    +----------------+-----------------+-----------------------------------+
    | NodeAgent与    | 运行时解耦      | 编译独立、动态加载、版本兼容      |
    | SDK关系        |                 | 可用其他语言实现NodeAgent         |
    +----------------+-----------------+-----------------------------------+
    | 配置执行方式   | 解释执行        | 无需编译、在线编辑即时生效        |
    +----------------+-----------------+-----------------------------------+
    | API风格        | 三种并存        | Easy(快速)、Core(精细)、C(外部)  |
    +----------------+-----------------+-----------------------------------+


    性能指标
    ========

    +----------------+----------------+----------------+----------------+
    | 启动时间       | 遥测插入       | Leader选举     | 任务分配       |
    | < 5s           | < 1ms          | < 15s          | < 100ms        |
    +----------------+----------------+----------------+----------------+
    | 状态转换       | 规则评估       | 内存占用       | CPU占用        |
    | < 100ns        | < 10μs         | < 256MB        | < 25%          |
    +----------------+----------------+----------------+----------------+

    快速启动命令
    ============

    # Builder启动
    cd FalconMindBuilder && docker-compose up -d

    # Console启动
    cd FalconMindViewer && ./start-dev.sh

    # NodeAgent编译
    cd FalconMindSDK/NodeAgent && mkdir build && cd build
    cmake .. -DCMAKE_BUILD_TYPE=Release && make -j4

    # SDK编译
    cd FalconMindSDK/build
    cmake .. -DCMAKE_BUILD_TYPE=Release && make -j4
