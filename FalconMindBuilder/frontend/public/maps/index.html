📍 昌平公园离线地图

FalconMindBuilder 离线地图配置指南

🎯 默认位置

昌平公园 (Changping Park)
纬度: 40.0768°N
经度: 116.3477°E
默认高度: 500m

当前系统已配置为使用 离线 Cesium 模式，默认显示昌平公园区域。

📥 下载离线地图

要获得最佳体验，请下载离线地图瓦片：

方法 1: 使用脚本（推荐）

cd FalconMindBuilder
./scripts/download-offline-maps.sh

选择地图类型：

  • 1 - OpenStreetMap 标准地图
  • 2 - 卫星图
  • 3 - 两者都下载

方法 2: 手动下载单个瓦片

# 创建目录
mkdir -p frontend/public/maps/tiles/osm/14/13271

# 下载中心瓦片
curl -o frontend/public/maps/tiles/osm/14/13271/6231.png \
  "https://a.tile.openstreetmap.org/14/13271/6231.png"

🚀 验证地图

  1. 下载完成后，启动前端开发服务器：
    cd frontend && pnpm dev
  2. 打开浏览器，访问地图编辑器
  3. 查看浏览器控制台，应该看到：
    Using offline map type: osm
